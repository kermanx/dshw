# 推送修复

用户已经确认当前工作区的修复，可以推送了。

1. 用 `git status`、`git diff` 确认工作区里就是这个 PR 的修复改动，没有多余文件（不要提交临时文件、日志、构建产物）。
2. 用一条清晰的 commit 提交（中文，说明修复了哪些评审意见），然后 `git push` 到当前分支 `{{branch}}`。
3. **不要** force push；不要创建/修改 PR 状态；不要改动目标分支。
4. 推送后用 `git log -1 --oneline` 确认提交，然后输出一行说明推了哪个提交。

最终回复最后一行必须是：

`DSHW_RESULT: completed`
