# 检查修复是否超出 PR 范围

你刚才根据评审意见修改了工作区，但还没有提交。现在请**只做审查，不要新增功能**：

1. 用 `git diff` 查看你这一轮的全部改动。
2. 对照这个 PR 原本的目标（`gh pr view {{prNumber}}`、`git log`），判断哪些改动**不是**评审意见要求的、也不属于这个 PR 的范围（例如顺手的重构、格式化、无关文件的修改、超前的设计）。
3. 如果有超范围的改动：**撤回它们**（把这些文件恢复到改动前的状态，只保留评审意见相关的修改）。可以用 `git checkout -- <file>` 恢复单个文件，但不要动你为修复评审意见所做的改动。
4. 如果没有超范围改动：说明"没有超范围改动"即可。

不要提交、不要推送。完成后输出一段简短说明：撤回了什么（或没有），以及剩余改动对应的评审意见。最后一行必须是：

`DSHW_RESULT: completed`
